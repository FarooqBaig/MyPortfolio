## How to add them

1. Rename your file to the name in the table.
2. Paste it here, replacing the placeholder.
3. PNG, JPG, or WebP works if you keep the same basename — PNG is preferred.
4. For the seventh credential, also send issue date, credential ID, and (if you have it) the public credential URL so they can be added in `js/config.js`.

Do not invent credential URLs in config until you have the real link.
